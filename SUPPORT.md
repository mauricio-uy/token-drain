# Support

Token Drain is an early-stage open-source project maintained by volunteers.
Please search existing issues before opening a new one.

## Installation and usage questions

Start with the [installation and usage guide](docs/guide.md). It covers:

- supported Windows versions and installer behavior;
- provider CLI sign-in and credential file locations;
- network hosts and privacy boundaries;
- cached usage, polling, and provider errors; and
- manual and automatic update behavior.

If the guide does not answer your question, open a
[support issue](https://github.com/mauricio-uy/token-drain/issues/new/choose)
with the application version, Windows version, and a concise description of
what you expected and what happened. Remove tokens, account identifiers, and
other private information first.

## Bug reports

Use the **Bug report** issue form for reproducible defects. Include sanitized
steps to reproduce, relevant provider and CLI versions, and the exact error
text when it contains no secrets. Do not attach credential files, crash dumps,
or unredacted logs.

## Feature requests

Use the **Feature request** issue form. Explain the user problem and the
proposed outcome rather than prescribing an implementation. Features that
require provider APIs not documented for consumer plans may not be feasible.

## Security issues

Do not use a public issue, pull request, discussion, or support request for a
vulnerability. Use GitHub's **Security → Report a vulnerability** flow. Read
[SECURITY.md](SECURITY.md) for scope and responsible disclosure guidance.
