# Code of Conduct

## Our pledge

We are committed to making participation in Token Drain a welcoming,
respectful, and harassment-free experience for everyone, regardless of age,
background, identity, experience level, or technology choices.

## Expected behavior

Examples of behavior that contribute to a positive environment include:

- being respectful and constructive;
- assuming good intent while addressing impact;
- giving and receiving feedback thoughtfully;
- focusing on what is best for the project and its users; and
- protecting private information, credentials, and security reports.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, unwanted sexualized
attention, publishing private information, and deliberately exposing secrets
or security details are not acceptable. Disagreement about an implementation is
welcome; hostility toward a person is not.

## Enforcement responsibilities

Maintainers are responsible for clarifying and enforcing these standards. They
may remove or edit comments, close discussions, or temporarily or permanently
restrict participation when behavior is unacceptable or harmful.

## Reporting

Report conduct concerns privately to the project maintainer through the
[maintainer's GitHub profile](https://github.com/mauricio-uy). Do not include
security vulnerability details in a public issue. Security reports belong in
GitHub's **Security → Report a vulnerability** flow; see [SECURITY.md](SECURITY.md).

Reports will be handled respectfully and as confidentially as practical.

## Scope

This code of conduct applies within project spaces and whenever someone is
officially representing the project in public spaces.
