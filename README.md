# Token Drain

A minimal Windows desktop widget that shows usage and rate limits for Claude,
Codex, and OpenCode Go subscriptions at a glance.

**100% vibe-coded.** The entire project was built through AI-assisted coding.

How data is collected: [Claude](docs/claude.md) · [Codex](docs/codex.md) ·
[OpenCode Go](docs/opencode.md).
